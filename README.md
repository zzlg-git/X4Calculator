# X4Calculator

X4Calculator 是一款基于 .NET 8 WPF 的 Windows 桌面应用，用于在本地分析《X4：基石》的生产链、空间站规划、存档、星区地图、舰船装配和运输效率。

应用不依赖在线数据，不读取游戏内存。游戏基础数据由用户从自己的 X4 安装目录导出，存档也只在本机解析。

## 首次运行

0. 下载NoRuntime后缀的压缩包，解压后参照其内部的readme前往微软官网下载runtime。或者下载Full后缀的压缩包解压。
1. 确认电脑已安装 X4。
2. 启动应用。若应用目录没有有效的 `GameData`，首页会进入数据准备流程。
3. 使用自动发现或手动选择指定 X4 安装目录。
4. 选择需要导出的基础游戏、官方 DLC 和可选 MOD，然后确认开始。
5. 导出完成后，应用会自动加载游戏数据和星区地图，首次进入加载时间较长，建立缓存后加载时间会大幅缩短。
6. 导入存档，存档为流式读取，不会将整个存档塞入内存。
7. 若字体较小，可使用Ctrl+=、Ctrl+-、Ctrl+0进行缩放。

## 主要功能

### 本地游戏数据准备

- 首次运行时自动查找 Steam 等位置中的 X4 安装，也可手动选择游戏目录。
- 提供“原版游戏数据导出”和“包含 MOD 的数据导出”两种入口。
- 导出前列出基础游戏、官方 DLC 和检测到的 MOD；基础游戏不可取消，其他项目可自行选择。
- 显示导出进度并支持取消；取消或失败不会覆盖已有的可用数据。
- 从本地 `GameData` 解析商品、文本、生产配方、生产模块、空间站模块、舰船、引擎、推进器、建造材料和星图数据。
- 当前计算模型加载基础游戏及目录名为 `ego_dlc_*` 的官方 DLC。第三方 MOD 可被导出保存，但尚未全部进入计算模型，不保证计算数据的准确性。

### 生产链路

- 区分工业、农业以及特殊的回收和处理生产链。
- 支持不同种族、生产方式和建造方式对应的配方谱系。
- 按原料、中间产品和最终产品层级筛选商品，以红黄绿三色区分，红色为可无中生有的原料，绿色为劳动力物资或船只建造所需。
- 递归生成从投入到产出的生产关系。
- 计算单模块及生产链的每分钟、每小时投入和产出。
- 汇总上游供给需求并显示产能缺口。

### 产线编排

- 分组管理从存档导入的空间站和应用内创建的计划站。
- 搜索、筛选、排序并添加生产、居住、仓储、船厂等空间站模块。
- 分别显示当前已建模块、建设序列和规划模块的产能。
- 根据产能缺口自动补齐中间产品。
- 计算劳动力需求、人口容量、增长时间、拥挤状态和劳动力生产加成。
- 处理不同种族的劳动力食品与医疗物资需求。
- 支持光照效率、常规/TER/闭环等建造偏好及舰船建造材料估算（体现于自动仓储量，当前版本未显式显示）。
- 支持废料处理设施的标准/全速模式及多产品筛选（即控制仓储以单独生产一种），标准为1000废料上限情况，全速为无间断运行理想情况。
- 自动区分工厂、贸易站和终端站/船厂职责，也可手动选择。
- 管理集装、固体和液体仓储容量、自动分配及手动数量上限。
- 查看和编辑买卖报价、自动价格、价格覆盖与贸易规则。
- 构建跨站运输网络，选择运入/运出链路，并计算运输时间和吞吐效率。
- 在星区地图中为计划站选择扇区和放置位置。

### 存档导入

- 从默认 X4 存档目录选择存档，或通过文件选择器导入 `.xml.gz` 存档。
- 显示游戏内存档名、文件名和修改时间。
- 使用流式解析处理大型 XML/gzip 存档，并支持取消。
- 恢复玩家空间站、模块、建设序列、仓储、报价、贸易规则、劳动力、管理员星级和下属舰船等运营字段。
- 读取玩家蓝图、势力与扇区归属、NPC 站、黑市岗位和数据仓库、异常点等。
- 一次只应用一个存档；取消已完成的导入会清除当前存档覆盖层。

### 星区地图

- 根据本地 X4 数据重建 Cluster、Sector、Zone、星门和超级高速路层级。
- 显示扇区归属及势力颜色。
- 支持玩家空间站与 NPC 空间站显示模式切换。
- 显示或高亮黑市相关空间站、Kha'ak 空间站、无主舰船、数据保险库和异常点等对象。
- 支持缩放、平移、悬浮信息和空间站名称显示。
- 显示已选择空间站之间的运输方向、货物、路线和动态箭头。
- 计划站与存档空间站使用相互独立的地图覆盖层。

### 舰船装配与运输效率

- 按舰船、尺寸、用途、仓储类型、推进器、引擎和驾驶员技能筛选配置。
- 计算常规速度、加速度、制动、转向和旅行模式相关飞行属性。
- 估算巡航、旋转、进港、离港和分段路线耗时。
- 支持跨扇区路线、星门与超级高速路穿越及距离明细。
- 根据货舱容量和路线总耗时计算运输效率（`m³/s`）。
- 枚举并排序可用舰船、推进器和引擎组合。
- 为产线编排中的运输网络计算并比较全局运输配置。
- 按集装、固体、液体、冷凝以及大型/小型舰船槽位保存共享配置。

### WPF 桌面界面

- 包含“首页”“生产链路”“产线编排”“存档导入”“星区地图”“运输效率计算”六个主要页面。
- 游戏数据和星图在后台顺序加载，界面加载期间保持可操作。
- 状态栏统一显示加载、导入、错误和帮助信息。
- 支持应用整体缩放和 Windows 深色界面。

## 当前范围与限制

- 仅支持 Windows x64。
- 不读取游戏内存，不连接游戏实时状态，也不提供在线数据服务。
- 当前只将基础游戏和官方 DLC 数据载入计算模型；第三方 MOD 会和原生游戏一样被解析，但并非所有 MOD 的修改都已载入计算模型。
- 一次只查看一个存档，不提供多存档对比。
- 不生成可导入游戏的空间站建造计划，也不替代游戏内建造界面。
- 尚未实现按实时市场价格计算利润和回本周期。
- 部分游戏内部动态状态没有稳定的存档字段且部分依赖游戏随机种子，应用不会用推测值冒充精确结果，需要随机生成的部分不保证准确仅计算均值。
- 计划站的地图位置是本工具的规划输入，目前仅能放在六边形范围内，不能再现 X4 引擎中的无限建造边界。

### 已验证支持的mod

- deadair_eco_no_da_wares ，带DAware的版本理论上也支持，未验证

## 下一步开发计划

序号不代表重要性或开发顺序。

1. 将运输效率计算TAB中“进/离港耗时”的经验公式改为游戏实际使用的公式，当前已接入Core但未经完整验证，暂不接入UI。
2. 完善自动补全功能，增加居住和仓储模块的补全。
3. 根据仓储大小、产能和运输舰船配置，自动计算提高运输效率的最有效途径。
4. 根据当前游戏配置自动选择数据导出时导出的dlc和mod。
5. 完善功能说明，增加“这是什么？”悬浮窗。
6. 优化底部错误提示栏的显示时间，增加更多信息显示。
7. 重构存档导入逻辑，进一步提升速度。
8. 增加用户偏好配置保存。
9. 增加部分mod支持。
10. 增加浅色模式。
11. 增加多语言支持。
12. UI方案迁移至NativeAOT。

## 仓库不包含的内容

- 解包后的 X4 游戏数据和官方 DLC 数据。
- X4 存档、诊断日志、研究采样和运行时捕获结果。
- 编译、测试和发布产物。
- X4 的专有星图纹理；缺少这些纹理时，公开源码版本使用内置几何图标作为回退。

用户必须拥有合法的 X4 安装，并从自己的安装目录生成运行所需数据。但本应用不会代替提供商也不会使用相关手段验证用户的X4应用程序来源，也不会修改本应用目录外的任何数据。

## 项目结构

```text
X4Calculator.Core/  纯 .NET 计算、数据加载、模型和存档解析
X4Calculator.UI/    WPF 界面、ViewModel、服务、样式和发布配置
X4Calculator.sln    包含 Core 与 UI 的解决方案
```

公开仓库采用最小可构建结构，不包含原项目中的测试数据、研究记录、诊断探针和内部工具。
